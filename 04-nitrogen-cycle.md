# Nitrogen Cycle (with Diagram)

## Diagram

```
         ATMOSPHERE (N₂ — 78%)
              │           │
    ┌─────────▼──┐   ┌────▼──────────┐
    │ N₂ FIXATION│   │ INDUSTRIAL    │
    │ Rhizobium, │   │ (Haber-Bosch) │
    │ Azotobacter│   │ → Fertilisers │
    │ Lightning  │   └────┬──────────┘
    └─────┬──────┘        │
          ▼               ▼
      NH₃ / NH₄⁺ (Ammonia/Ammonium)
          │
    ┌─────▼──────────────┐
    │ NITRIFICATION      │
    │ Nitrosomonas: NH₄⁺→NO₂⁻ │
    │ Nitrobacter:  NO₂⁻→NO₃⁻ │
    └─────┬──────────────┘
          ▼
    NO₃⁻ absorbed by PLANTS
          │
    ASSIMILATION → Amino acids, proteins
          │
    Animals eat plants → food chain
          │
    AMMONIFICATION (death/decay → NH₃)
          │
    DENITRIFICATION (Pseudomonas)
    NO₃⁻ → N₂O → N₂ → back to atmosphere
```

## 10 Points

1. **Nitrogen Fixation** — N₂ converted to NH₃ by Rhizobium (in legume roots), Azotobacter, cyanobacteria, and lightning.

2. **Industrial Fixation** — Haber-Bosch process (N₂ + 3H₂ → 2NH₃) produces ~150M tonnes of ammonia/year for fertilisers.

3. **Nitrification** — Nitrosomonas converts NH₄⁺ → NO₂⁻; Nitrobacter converts NO₂⁻ → NO₃⁻. Both are aerobic soil bacteria.

4. **Assimilation** — Plants absorb NO₃⁻ through roots → build amino acids, proteins, DNA, chlorophyll. Animals get N by eating plants.

5. **Ammonification** — Decomposers break dead matter/excreta back into NH₃/NH₄⁺, returning nitrogen to soil.

6. **Denitrification** — Pseudomonas (anaerobic) converts NO₃⁻ → N₂O → N₂, releasing nitrogen back to atmosphere. Occurs in waterlogged soils.

7. **Human Disruption: Fertilisers** — Haber-Bosch doubled reactive nitrogen input. Runoff causes eutrophication → algal blooms → dead zones (Gulf of Mexico).

8. **N₂O & Climate** — Nitrous oxide is ~300× more potent than CO₂ as a greenhouse gas. Agriculture is a major source. Also depletes ozone.

9. **Acid Rain** — Fossil fuel burning releases NOₓ → reacts with water → HNO₃ (nitric acid). Damages forests, lakes, and buildings like Taj Mahal.

10. **Groundwater Pollution** — Excess NO₃⁻ leaches into drinking water. >10 mg/L causes **blue baby syndrome** (methemoglobinemia) in infants.
